# SPARK public catalog

Public, attributed research summaries for the SPARK iPhone app. No account credentials, personal saves or recommendation histories are stored here.

The app reads `catalog.json`. Immutable research snapshots are in `versions/`. Each item retains its original publication date, source evidence, and last verification date. Summaries and suggested prompts are editorial adaptations, not endorsements or verified guarantees. Creator media remains hosted at its source.
